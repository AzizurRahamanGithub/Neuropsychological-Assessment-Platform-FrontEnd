================================================================================
QUESTION TYPES & EXAMPLES
================================================================================

TYPE 1: TEXT INPUT
──────────────────
Use For:  Open-ended responses, age, descriptions
Example:  "A che età hai notato questi sintomi?"
Options:  NOT NEEDED
Storage:  User types free text

TYPE 2: SINGLE CHOICE (Radio Buttons)
──────────────────────
Use For:  One answer only, Likert scales, yes/no
Example:  "Hai difficoltà a concentrarti?"
Options:  REQUIRED (minimum 2)
Storage:  Selected option value (typically 0-4)

Sample Likert Scale:
├─ Mai (0)           - Never
├─ Raramente (1)     - Rarely
├─ A volte (2)       - Sometimes
├─ Spesso (3)        - Often
└─ Molto spesso (4)  - Very Often

TYPE 3: MULTIPLE CHOICE (Checkboxes)
──────────────────────
Use For:  Multiple answers allowed, life domains
Example:  "Aree di vita compromesse (seleziona tutte)"
Options:  REQUIRED (minimum 2)
Storage:  Selected option values (typically 0 or 1 per option)

Sample Domain Selection:
├─ Lavoro/Scuola (1)    - Work/School
├─ Relazioni (1)        - Relationships
├─ Attività ricr. (1)   - Recreation
├─ Autostima (1)        - Self-esteem
└─ Guida (1)            - Driving

================================================================================
SCORING FIELDS AVAILABLE
================================================================================

disattenzione          → Inattention symptoms (questions 1-8)
iperattivita           → Hyperactivity symptoms (questions 9-12)
impulsivita            → Impulsivity symptoms (questions 13-15)
sct                    → Stress/Trauma history
eta_inizio             → Age of symptom onset
ambiti_compromissione  → Life domain impairment areas
diagnosi_precedente    → Previous ADHD diagnosis

SCORING PATTERN (ADHD Scale):
├─ Questions 1-8:   Disattention (0-4 each, max 32)
├─ Questions 9-12:  Hyperactivity (0-4 each, max 16)
├─ Questions 13-15: Impulsivity (0-4 each, max 12)
├─ Question 16:     Age of onset (multi-choice)
├─ Questions 17-21: Impairment domains (yes/no)
└─ Questions 22-27: Clinical history (yes/no)

================================================================================
VALIDATION RULES
================================================================================

✅ REQUIRED (Cannot Submit Without):
   ├─ Questionnaire Code (unique, uppercase, underscore-separated)
   ├─ Questionnaire Name (non-empty)
   ├─ Questionnaire Type (SELF or OTHER)
   ├─ At least 1 question
   └─ For choice questions: at least 1 option

❌ INVALID (Will Show Error):
   ├─ Empty code field
   ├─ Empty name field
   ├─ Empty question text
   ├─ Choice question without options
   ├─ Empty option text
   └─ No questions added

⚠️  WARNINGS (Best Practices):
   ├─ Clear question wording
   ├─ Consistent scoring systems
   ├─ Logical question order
   └─ Assign scoring fields where relevant
